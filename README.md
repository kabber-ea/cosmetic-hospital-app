# CosmeticCare Asia React App

A Vite + React + Tailwind demo app for listing cosmetic hospitals in China, Japan and Korea.

## Features

- Landing page with search and country dropdown filter
- Hospital detail pages
- Procedure detail pages with doctors
- Red legal policies / authorities button
- Helpdesk form
- Language switcher: English, Chinese, Korean and Japanese
- JSON-driven data in `src/data/hospitals.json`
- No login and no database required

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Replace data later

Edit `src/data/hospitals.json` or replace it with API/database data when your backend is ready.
